# Engineering

這個資料夾保存 SuikContentLab 中與軟體工程相關的公開文章與內容資產。

目前先分成三個主要方向：

- `Architecture/`：架構設計、模組邊界、系統拆分、Migration 與工程決策。
- `AI-Augmented-Engineering/`：AI 輔助軟體工程、Agent Harness、Context / Prompt / Workflow 設計等。
- `Engineering-Notes/`：較短篇、偏實務觀察、踩坑、工具與開發細節的分享。

分類只負責主要語意；跨主題內容可透過文章 metadata / tags 補充，不需要為每個技術關鍵字建立資料夾。
