# Architecture

保存偏架構設計、系統邊界與工程決策的內容。

目前依 LinkedIn 內容形式區分：

```text
Architecture/
├─ Post/
└─ Article/
```

- `Post/`：Feed 型短文，一篇聚焦一個主要觀點。
- `Article/`：需要完整背景、架構、案例與 Trade-off 的長篇內容。

例如可涵蓋：

- SysCore / Feature / SpecFeature
- Modular Architecture
- Dependency Boundary
- Legacy System / Migration
- SSR / Hydration 架構
- 大型系統拆分
- Architecture Trade-off

同一主題可以先發多篇 Post，再整理成一篇較完整的 Article。
