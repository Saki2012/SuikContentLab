# Post

保存 LinkedIn Feed 型短文／貼文。

定位：

- 用 Hook 快速切入一個工程問題或觀察。
- 一篇原則上只承擔一個主要 Resolve。
- 重視 Feed 閱讀體驗、短段落、留白與掃讀性。
- 可以使用少量 Emoji 當視覺路標。
- 結尾可依情境加入 Conversation / Continuation / Service CTA。
- 正文應以純文字貼到 LinkedIn 後仍然好讀為優先。

Post 的主要用途是：

> 被看見、建立認知、引發討論，並把值得深入的主題導向後續內容。
