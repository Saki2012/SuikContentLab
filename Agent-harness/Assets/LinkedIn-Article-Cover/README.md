# LinkedIn Article Cover Examples

這個資料夾用來保存 SuikContentLab 的 LinkedIn Article 封面參考圖。

## 角色定位

「澪 / Mio」是 SuikContentLab 的固定看板娘與主要視覺入口。

新增範例圖時，主要用來提供：

- 澪的角色外觀與氣質參考
- 封面人物與標題的比例
- 技術元素的視覺呈現方式
- 不同 Article 主題下的場景與構圖參考
- 後續生成封面時的品牌一致性

不要求每篇完全複製相同構圖。

目標是讓不同封面仍然能讓讀者逐漸建立：

> 「這是 SuikContentLab / Suik 的文章」

的辨識。

## 檔案管理

圖片由 Repository 根目錄的 `.gitattributes` 規則交給 Git LFS 管理。

建議檔名保留文章主題，例如：

```text
architecture-three-layers-cover.png
ai-agent-harness-cover.png
legacy-system-cover.webp
```

避免使用無法辨識用途的 `image1.png`、`final-final-2.png` 等命名。
